> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a polished 40-48 page A4 memorial booklet for Prof. Miriam Ngozi Mgbakor as a print-ready PDF and a layout-faithful editable PowerPoint source, grounded in the memorial website, live tributes, site-uploaded photographs, family archive and verified academic sources.

**Architecture:** Build a deterministic data-and-layout pipeline. Read-only capture scripts create privacy-safe tribute and photo manifests; a manually curated editorial JSON file controls biography, tribute excerpts, page order and captions; a PptxGenJS builder uses shared design tokens and reusable page masters to generate an editable custom-size PPTX; LibreOffice exports the same source to PDF; Python/Poppler verification scripts render and audit every page. The final PDF and PPTX are generated from the same content model so edits remain reproducible.

**Tech Stack:** Bundled Codex workspace Node.js and Python runtimes, PptxGenJS, Sharp, Python Pillow, pypdf, pdfplumber, Poppler, LibreOffice, Vitest or Node's built-in test runner, WCAG contrast calculations.

- [ ] **Step 2: Implement WCAG luminance and alpha-compositing**

```js
export function contrastRatio(foreground, background) {
  const luminance = (hex) => {
    const rgb = hex.match(/[0-9a-f]{2}/gi).map((part) => parseInt(part, 16) / 255);
    const [r, g, b] = rgb.map((v) => v <= 0.04045 ? v / 12.92 : ((v + 0.055) / 1.055) ** 2.4);
    return 0.2126 * r + 0.7152 * g + 0.0722 * b;
  };
  const a = luminance(foreground);
  const b = luminance(background);
  return (Math.max(a, b) + 0.05) / (Math.min(a, b) + 0.05);
}
```

`assertReadableOverlay` must require 4.5:1 for text under 18 pt (or under 14 pt bold), 3:1 for larger text, and test every sampled background colour. A solid panel automatically uses its declared panel colour; a photograph never passes merely because its average colour passes.
